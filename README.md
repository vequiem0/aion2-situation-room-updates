# AION2 Situation Room Updates

AION2 상황실의 공개 업데이트 배포 전용 저장소입니다.

- 프로그램 소스코드와 계정·캐릭터·설정 데이터는 공개하지 않습니다.
- Releases에는 서명된 `latest.json`과 업데이트 ZIP만 게시합니다.
- 상황실은 버전을 자동 확인하고, 사용자가 **업데이트**를 선택하면 다운로드·검증 후 재시작합니다.
- **나중에**를 선택하면 이번 실행 중 같은 버전 알림을 생략합니다.
- 기존 계정·캐릭터·설정 데이터는 유지됩니다.
- 업데이트 ZIP은 기존 네이티브(WPF) 버전용이며 신규 설치 파일이 아닙니다.

버전 안내: https://github.com/vequiem0/aion2-situation-room-updates/releases/latest/download/latest.json

비공식 보조 도구입니다. AION2 및 게임 관련 상표·이미지의 권리는 해당 권리자에게 있습니다.
